# 🧁 Management Pastry Shop

A **Spring Boot web application** for managing a pastry shop.  
This system provides a simple and structured way to manage **products**, **sales**, and **dashboard statistics** through a user-friendly interface.

---

## 🚀 Features

The application contains **3 main interfaces**:

### 📊 Dashboard
- Overview of the pastry shop activity
- Display key statistics (products, sales, etc.)
- Central access to all management features

### 🛠️ Product Management
- Add new pastries
- Update existing products
- Delete products
- Manage pastry details (name, price, quantity, etc.)

### 💰 Sales Management
- Register sales
- Track sold products
- Manage sales records

---

## 🧩 Tech Stack

- **Backend:** Spring Boot
- **Frontend:** Thymeleaf / HTML / CSS (in process)
- **Database:** MongoDB
- **ORM:** Spring Data JPA (Hibernate)
- **Build Tool:** Maven
- **Java Version:** Java 8+
